# Live generated reports

Status: generated
Author: tools/collect_daemon.py

`REPORT_YYYY-MM-DD.md` files are daily summaries of collector receipts: cadence, captured slots,
failures, last captured time, age, rows and measurement-time status.

They are generated by:

```text
tools/collect_daemon.py report
```

They are not edited by hand and are ignored in the private source repo. The public publisher copies
them to the public mirror when present, because the public mirror is the archive of public live state.
